## 页面结构

首页是纯静态 HTML + CSS + 一点点原生 JS，不依赖 React / Babel / CDN，
断网也能正常打开。布局照着草图来：**左边一个粉色圆环头像 + 右边 3 条资料 + 1 条大自我介绍**。

| 文件 | 说明 |
| --- | --- |
| `index.html` | 首页（图标 SVG 已内联，颜色跟随主题；含背景装饰层、头像轨道贴纸和动效按钮） |
| `styles.css` | 全部样式：浅色 / 深色、电脑 / 手机适配、打印样式，以及整套动效关键帧 |
| `script.js` | 主题切换、动效开关、年龄、状态打字机、猫猫伙伴、猫猫雨、吐槽气泡、随机恶作剧等交互 |
| `about/index.txt` | 个人资料原稿（改文案从这里开始） |
| `icon/` | 头像 `head.PNG`、`logo.svg`、网页图标 `favicon.svg`、分享大图 `og-cover.png`、各个社交图标 |
| `font/arial-unicode-subset.woff2` | 只含本站用字的网页字体（约 195 KB） |

### 动效与小互动

「能动就动」是这一版的主线，但所有动画都只改 `transform` / `opacity`，
并且完整尊重系统的「减少动态效果」设置：

- **背景**：三团慢慢游动的模糊光斑 + 十几颗飘来飘去的小 emoji；深色模式会亮起星屑，
  鼠标移动时光斑、头像和涂鸦还有不同深度的视差（手机上自动收起）。
- **头像**：粉色圆环外圈有旋转的柔光和虚线圈，四枚小贴纸绕着圆环转；
  头像轻轻浮动、跟着鼠标微移、悬停放大歪头。
- **猫猫雨**：连戳头像 5 下，会下一场猫猫雨并播报「猫咪快点统治世界吧！！！」；
  提示台词会从「喵？」一路嫌弃到「再 1 下就下雨！」，每次都冒一个 (>_<) 气泡。
- **猫猫伙伴**：桌面端有一只 🐱 跟着鼠标跑（带缓动和倾斜），点任意位置它会「喵」；
  停下来两秒多会自己溜走，不挡着看介绍。
- **散步猫猫**：每隔一会儿，会有一只 🐈 从白色面板底部慢悠悠走过去。
- **状态牌**：头像下方的「果果的状态」用打字机轮播做游戏 / 画画 / 电视 / 古籍 /
  特仑苏 / 巧克力 / 猫咪…，点一下换一句；点爱好或生日卡片也会切到对应台词。
- **吐槽气泡**：页面会随机冒出一句悄悄话（「页面上藏着 17 只猫，找找看？」）；
  发呆 18 秒会被调侃；切走标签页，标题会变成「别走！猫咪在等你… 🐾」。
- **躲闪的 emoji**：鼠标靠近爱好标签，emoji 偶尔会躲一下；「仍在寻找…」的答案
  也不正经（「睡觉算爱好吗？」）。
- **页脚爱心**：页脚的小爱心可以点，连点 3 下状态牌会「爱心能量满啦！」。
- **随机恶作剧**：名字偶尔来一波波浪、轨道贴纸逆行、头像闪星星、猫猫伙伴转圈。
- **卡片**：鼠标移动时有 3D 倾斜 + 跟着鼠标的柔光，悬停时掠过一道扫光。
- **文字**：名字逐字拆开做渐变流动并持续小波动，悬停整行会像波浪一样弹跳；
  新结尾「一起交朋友呀！❤️❤️❤️❤️❤️☆˶> x <˶.⁺」的爱心按拍跳动；
  荧光笔从左往右刷过，分隔虚线一直在跑。
- **小东西**：别称 / 爱好 / 账号依次蹦出来，悬停会跳一下，平时也会轻轻浮动；
  颜文字每 3.5 秒自动换，点一下还能再换一个并撒爱心。
- **点击**：点链接、标签、卡片甚至空白处都会在鼠标位置撒花 / 冒星星；
  鼠标划过留下星尘；主题切换会在支持的浏览器里从按钮位置圆形擦除到新配色。
- **开关**：右上角 ✨ 可以随时暂停 / 恢复全部动效（包括状态打字机、猫猫伙伴、
  环境爱心、猫猫雨、散步猫猫、吐槽气泡和发呆调侃；偏好记在
  `localStorage.stukdee_motion`）；系统开启「减少动态效果」时默认静止，
  点一下 ✨ 也能手动打开。

全部交互都有键盘焦点样式；头像、状态牌、颜文字和爱好标签都能 Tab 聚焦，
回车 / 空格能按。

### 手机适配

- `> 900px`：左右两栏（头像在左，资料在右）
- `≤ 900px`：改成上下堆叠，头像居中在上
- `≤ 620px`：收紧间距、缩小圆环、账号两列
- `≤ 380px`：账号图标一行两个

深色模式：跟着系统走，也可以在右上角按钮手动切换
（存在 `localStorage.stukdee_theme`，也支持 `?theme=dark` / `?theme=light` 直接打开）。

## 重新构建

网页字体是从 22MB 的 `Arial Unicode.ttf` 里**抽取本站用到的字**生成的。
抽取范围包括 `index.html` 正文、`aria-label` / `title` / `alt` / meta `content` /
`data-say`、CSS 里的 `content: "…"`，以及 `script.js` 里会显示出来的文字
（颜文字、状态台词、按钮文案等）。
改了页面文案以后，重新跑一次即可：

```bash
# 1. 安装依赖（仓库内虚拟环境，不会污染系统）
python3 -m venv .tools-venv
.tools-venv/bin/pip install fonttools brotli

# 2. 把原始字体放回 font/Arial Unicode.ttf（22MB，未入库）
#    然后重新生成子集
.tools-venv/bin/python build-font-subset.py

# 3. 新增/替换图标后，重新内联 SVG
python3 build-inline-icons.py

# 4. logo.svg 有改动时，重新生成网页图标
python3 build-favicon.py

# 5. 改了首页文案 / 头像 / logo 后，重新生成分享预览大图
python3 build-og-image.py
```

### 网页图标

浏览器标签页上的图标由 `icon/favicon.svg` 提供，它**由 `icon/logo.svg` 生成**
（`build-favicon.py`）：裁掉 A4 空白、补一层浅色圆形底、把"毫米级"的线宽加粗到
小尺寸能看清的程度。所以改 logo 之后记得重跑一次 `build-favicon.py`。
`icon/head.PNG` 作为 `rel="alternate icon"` 保留，给不支持 SVG 图标的极老浏览器兜底。

### 分享到 X（推特）

链接发到 X 上会显示成**大图卡片**，靠的就是 `index.html` 里这几行：

```html
<meta property="og:image" content="https://stukdee.is-a.dev/icon/og-cover.png">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta name="twitter:card" content="summary_large_image">
```

三个要点：

1. **图片必须是绝对 URL**（`https://…`），相对路径 X 抓不到；
2. **横图 1200×630** 才会显示成大图。用方图 + `summary` 只会缩成角落里的小方图；
3. **X 会缓存旧预览**，换图后不会立刻更新，等几分钟到几小时，或者用
   [Card Validator](https://cards-dev.twitter.com/validator) / 在链接后加 `?v=2` 强制重抓。

`icon/og-cover.png` 由 `build-og-image.py` 生成：它把字体、logo、头像全部内联进
`.og-template.html`（模板在脚本里的同名文件），再用无头 Chrome 渲染成 1200×630。
改版式就改模板，改完重跑脚本。想快速自查效果，把链接发到 Telegram 的「Saved Messages」
或 Discord，它们抓取快、不缓存。
